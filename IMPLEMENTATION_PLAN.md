# План реализации Hunger Games

Основание: `TODO.md` и согласованные ответы от 16.10.2026.
Minecraft 1.21.1, API NeoForge 21.1.250 (проверен сервер 21.1.256), Java 21, пакет `ru.studhub.hungergames`.

`[X]` — требование согласовано или подготовительная работа выполнена.
`[ ]` — реализация, проверка либо решение ещё предстоит.
Отмеченные требования не означают, что соответствующая механика уже реализована.
Реализация начата по разрешению пользователя. Статус реализации отмечается отдельно от согласованных требований.

## 1. Согласованные требования

- [X] Hunger Games устанавливается только на сервер; клиентам отдельный мод Hunger Games не требуется.
- [X] Набор открывается ежедневно в 20:00 по Москве, часовой пояс `Europe/Moscow`.
- [X] Сервер сообщает об открытии набора в общий чат и приглашает использовать `/hg invite`.
- [X] Если за 15 минут не набралось минимум четыре игрока, набор закрывается.
- [X] Одновременно участвуют от четырёх до восьми игроков.
- [X] Вход разрешён только с пустыми инвентарём, бронёй, второй рукой и аксессуарами.
- [X] После входа игрок переносится в зону ожидания; исходное место сохраняется.
- [X] При четырёх участниках начинается отсчёт в три минуты; при восьми оставшееся время сокращается до 15 секунд.
- [X] При числе участников меньше четырёх отсчёт сбрасывается. В остальных случаях таймер не сбрасывается.
- [X] Игра проходит на готовой карте в отдельном измерении.
- [X] Команда `/hg set_spawn <player_num>` сохраняет текущее положение как точку появления участника с номером от 1 до 8.
- [X] Сундуки уже размещены на карте; перед каждым боем они заполняются случайным лутом из общего пула.
- [X] На карте CITY UHC бочки также заполняются общим игровым лутом; подтверждено пользователем.
- [X] Арена неразрушаемая: игрокам запрещены установка и разрушение блоков.
- [X] Зона боя сужается; для её реализации предполагается использовать границу мира.
- [X] После старта нет периода неуязвимости.
- [X] При смерти вещи выпадают, а игрок становится наблюдателем.
- [X] Команда `/hg leave` позволяет покинуть очередь или наблюдение.
- [X] Уточнение после начала реализации: отключение от сервера считается поражением с выпадением игровых вещей.
- [X] После перезапуска сервера игроки возвращаются на сохранённые места вне игрового измерения.
- [X] Последний оставшийся участник становится победителем: поздравление, очистка игрового инвентаря, возврат, выдача награды.
- [X] Основные награды и лут сундуков задаются отдельными JSON-пулами; содержимое позже заполнит администратор.
- [X] Звезда незера — отдельный бонус к основной награде; предмет бонуса должен быть заменяемым через настройки.
- [X] Вероятность бонуса зависит от числа участников в момент начала боя: 4 → 20%, 5 → 40%, 6 → 60%, 7 → 80%, 8 → 100%.
- [X] Нужны административные команды, включая `/hg create_event`, и команда просмотра `/hg spectator`.
- [X] Административная `/hg start_event` принудительно запускает бой с текущим составом независимо от минимального количества участников и оставшегося отсчёта.
