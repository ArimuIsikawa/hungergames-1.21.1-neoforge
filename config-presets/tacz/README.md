# Пулы Hunger Games с оружием TaCZ

## Сундуки

`chest_loot.json` подготовлен для установленной сборки
`tacz-neoforge-1.21.1-1.1.8-hotfix-r6-studhub.jar` и её `tacz_default_gun`.
Он уже установлен в `C:\Users\SSD\Desktop\test_server\config\hungergames\chest_loot.json`.
Для другого сервера скопируйте файл в `config/hungergames/chest_loot.json`
и выполните `/hg reload` вне события. Нужна версия Hunger Games с поддержкой `companions`, `guaranteed` и `pools`.

Всего 51 вариант в двух частях пула. Каждый сундук получает ровно одно оружие
с обязательными патронами из группы `pools` и 3–6 выборок брони/еды из `entries`;
выбранное оружие дополнительно добавляет отдельный стак подходящих патронов.
Количество занятых слотов — от 5 до 8. Еда и элементы брони могут повторяться.

| Категория | Модели |
| --- | --- |
| Пистолеты и револьверы | Glock 17, M1911, M9A4, Desert Eagle, Rhino 357 |
| Пистолеты-пулемёты | MP5A5, UMP45, Uzi, Vector, P90 |
| Автоматы и винтовки | AK-47, M4A1, M16A4, HK416D, AUG, SCAR-L, SCAR-H, QBZ-95 |
| Дробовики | M870, M1014, SPAS-12, двустволка DB Long |
| Самозарядные винтовки | SKS Tactical, Mk14 |
| Винтовки с продольно-скользящим затвором | Kar98, M700 |
| Пулемёты | M249, RPK |

Barrett M95 (`tacz:m95`), Barrett M107 (`tacz:m107`) и AWM (`tacz:ai_awp`)
исключены из пула. Оружие выдаётся разряженным с корректным режимом огня:
перед использованием его нужно перезарядить патронами из того же контейнера.

| Патроны | Количество на одну выборку оружия |
| --- | --- |
| 9 mm | 24–48 |
| .45 ACP | 20–40 |
| .50 AE | 7–21 |
| .357 Magnum | 12–24 |
| 5.56×45 | 30–60 |
| 7.62×39 | 30–60 |
| .308 | 20–40 |
| 5.8×42 | 30–60 |
| 12 Gauge | 8–16 |
| 7.92×57 | 8–16 |
| .30-06 | 10–20 |
| 5.7×28 | 30–60 |

Броня: шлем, нагрудник, поножи и ботинки из кожи, кольчуги, железа и алмазов.
Алмазные элементы встречаются реже остальных. Еда: хлеб, жареная говядина,
жареная свинина, жареная курятина, печёный картофель и золотая морковь.
Обычное золотое яблоко выдаётся по одной штуке с небольшим весом;
зачарованных золотых яблок в пуле нет.

Оружие и патроны связаны через `companions`: это один взвешенный выбор,
содержащий основной предмет и обязательные сопутствующие стаки. Чтобы изменить
запас патронов, отредактируйте `minCount`/`maxCount` в `companions` нужного оружия.
При замене `GunId` проверьте соответствующий `AmmoId` в установленном пакете TaCZ.

Проверено на NeoForge 21.1.256 с установленным TaCZ: API мода подтвердило все
28 моделей, их режимы огня и совместимость боеприпасов. Дополнительный GameTest
проверяет 5000 заполнений с ровно одним оружием на сундук. У каждого оружия есть подходящие
патроны. Для повторения серверной проверки используйте отдельный тестовый JAR,
аргумент Java `-Dhungergames.acceptance=true` и консольную команду
`hg_loot_acceptance` на резервной копии сервера без игроков.

## Награды победителя

`rewards.json` выдаёт полный комплект за каждую победу. Все ресурсы и яблоко
из `guaranteed` выдаются всегда; из каждой группы `pools` выбирается один вариант.

| Часть комплекта | Количество | Выбор |
| --- | --- | --- |
| Железные слитки | 16–32 | Всегда |
| Золотые слитки | 8–16 | Всегда |
| Алмазы | 2–5 | Всегда |
| Зачарованное золотое яблоко | 1 | Всегда |
| Оружие из 28 моделей выше | 1 оружие и 2 стака патронов | Равные шансы моделей |
| Шлем | 1 | Железный / алмазный / незеритовый, веса 3 / 2 / 1 |
| Нагрудник | 1 | Железный / алмазный / незеритовый, веса 3 / 2 / 1 |
| Поножи | 1 | Железные / алмазные / незеритовые, веса 3 / 2 / 1 |
| Ботинки | 1 | Железные / алмазные / незеритовые, веса 3 / 2 / 1 |

За победу выдаются все четыре части брони; материал каждой выбирается отдельно.
Всего комплект содержит 11 стаков до объединения. В наградах используются
те же проверенные модели оружия и калибры, что и в сундуках; Barrett M95/M107
и AWM исключены из обоих пулов. Каждый из двух стаков патронов имеет диапазон
количества из таблицы выше. После выдачи совместимые стаки могут объединяться
в инвентаре. Зачарованное золотое яблоко есть в наградах; в сундуках остаются
обычные золотые яблоки.

Звезда Незера разыгрывается дополнительно по настройкам `bonus`, отдельно
от основной награды и с учётом числа участников при старте боя.

Оба файла установлены в `test_server/config/hungergames`. Для переноса
скопируйте `chest_loot.json` и `rewards.json` в `config/hungergames`, затем
выполните `/hg reload` вне события. Загрузчик мода проверяет оба пула перед
применением; ошибочная конфигурация не заменяет предыдущую рабочую версию.
