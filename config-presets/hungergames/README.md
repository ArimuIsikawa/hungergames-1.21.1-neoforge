# Пулы Hunger Games с оружием TaCZ

## Сундуки

`chest_loot.json` подготовлен для установленной сборки
`tacz-neoforge-1.21.1-1.1.8-hotfix-r6-studhub.jar` и её `tacz_default_gun`.
Для другого сервера скопируйте файл в `config/hungergames/chest_loot.json`
и выполните `/hg reload` вне события. Для обоих пулов нужен Hunger Games **1.3.0 или новее**
с поддержкой `optionalCompanions` и вероятностей групп `chance`, а также Fracture Point и его зависимости
Curios/GeckoLib. Предметы проверяются по предоставленному
`fracturepoint-1.21.1-3.0.1-PT2-hotfix.jar`.

При обновлении остановите сервер и замените прежний JAR Hunger Games
на 1.3.0; в `mods` должна остаться одна версия мода. Затем скопируйте оба пула
и запустите сервер. Расписание, точки и другие поля `settings.json` менять не нужно.
Новый состав применяется при следующем заполнении контейнера. Ранее заполненные
нетронутые сундуки и бочки сохраняют содержимое по прежним правилам.

Для новых команд `/hg zona set center`, `/hg zona set speed <блоков_в_секунду>`
и `/hg zona set size <сторона>` нужен Hunger Games 1.2.0 или новее. Новый пул наград
требует 1.3.0; настройки карты при обновлении JAR сохраняются.

Всего 76 основных вариантов в двух частях пула. Каждый сундук получает ровно одно
оружие с четырьмя обязательными стаками патронов из группы `pools` и 3–6 выборок
брони, еды, пластин и рюкзаков из `entries`. Боезапас ивента повторно удвоен
относительно предыдущего пресета с двумя стаками. Дополнительно есть шанс 50%
получить один совместимый обвес к выбранному оружию. Количество стаков — от 8 до 12.
Обычные выборки допускают повторы.

| Категория | Модели |
| --- | --- |
| Пистолеты и револьверы | Glock 17, M1911, M9A4, Desert Eagle, Rhino 357 |
| Пистолеты-пулемёты | MP5A5, UMP45, Uzi, Vector, P90 |
| Автоматы и винтовки | AK-47, M4A1, M16A4, HK416D, AUG, SCAR-L, SCAR-H, QBZ-95 |
| Самозарядные винтовки | SKS Tactical, Mk14 |
| Винтовки с продольно-скользящим затвором | Kar98, M700 |
| Пулемёты | M249, RPK |

Barrett M95 (`tacz:m95`), Barrett M107 (`tacz:m107`) и AWM (`tacz:ai_awp`)
исключены из пула. Дробовики M870, M1014, SPAS-12 и DB Long также исключены
из сундуков и бочек: осталось 24 модели оружия. Оружие выдаётся разряженным с корректным режимом огня:
перед использованием его нужно перезарядить патронами из того же контейнера.

| Патроны | Суммарное количество в сундуке |
| --- | --- |
| 9 mm | 96–192 |
| .45 ACP | 80–160 |
| .50 AE | 28–84 |
| .357 Magnum | 48–96 |
| 5.56×45 | 120–240 |
| 7.62×39 | 120–240 |
| .308 | 80–160 |
| 5.8×42 | 120–240 |
| 7.92×57 | 32–64 |
| .30-06 | 40–80 |
| 5.7×28 | 120–240 |

Запас разделён на четыре стака, каждый выбирает количество независимо;
ограничения размера стака предмета соблюдаются.

Обычная броня: железные шлем, нагрудник, поножи и ботинки.
Из еды в общем пуле сундуков и бочек оставлены только стейки (`minecraft:cooked_beef`),
золотая морковь и обычные золотые яблоки. Стейки выдаются по 2–4 штуки с весом 10,
золотая морковь — по 1–3 с весом 4.
Обычное золотое яблоко выдаётся по одной штуке с небольшим весом;
зачарованных золотых яблок в пуле нет.

Fracture Point добавляет 32 элемента брони: по четыре части Ratnik, Beta 7,
Insurgency Commander, Soviet, SSO, FSB, IZ Forest и IZ Desert. Пять защитных
пластин: стальная III, керамическая IV, кевларовая IIIA, композитная IV
и полиэтиленовая III. Восемь рюкзаков: Ratnik, Shturmovik RU, NATO Squad Leader,
Insurgency Shturmovik, Soviet Soldier, SSO Soldier, IZ Forest и IZ Desert.
Каждая новая запись имеет вес 1 и количество 1; обычная броня и еда сохранены.

В `optionalCompanions` каждого оружия настроена одна группа с `chance: 0.5`.
При успехе выбирается один из совместимых вариантов с одинаковыми весами:
прицел, дульное устройство, приклад, рукоятка, магазин либо лазер.
Всего настроено 213 сочетаний оружия и обвеса; они проверяются через API TaCZ
и фактическую установку на копию оружия.
Обвес выдаётся отдельным предметом для самостоятельной установки.

Оружие и патроны связаны через `companions`: это один взвешенный выбор,
содержащий основной предмет и обязательные сопутствующие стаки. Чтобы изменить
запас патронов, отредактируйте `minCount`/`maxCount` в `companions` нужного оружия.
При замене `GunId` проверьте соответствующий `AmmoId` в установленном пакете TaCZ.

Проверено на NeoForge 21.1.256 с установленным TaCZ: API мода подтвердило все
модели оружия, их режимы огня и совместимость боеприпасов. GameTest проверяет
5000 заполнений с ровно одним оружием, четырьмя стаками патронов и не более чем
одним подходящим обвесом; отдельно проверяются установка каждого обвеса,
вероятность, вместимость и предметы Fracture Point. Прогон с полной сборкой:
`gradlew runGameTestServer -PhgFullPack` (моды размещаются в
`build/gametest-fullpack/mods`).

## Награды победителя

`rewards.json` выдаёт полный комплект за каждую победу. Ресурсы, яблоки,
четыре части брони, первое оружие и его обвес выдаются всегда. Вторая оружейная
группа имеет `chance: 0.25`, группа пластин — `chance: 0.5`.

| Часть комплекта | Количество | Выбор |
| --- | --- | --- |
| Железные слитки | 16–32 | Всегда |
| Золотые слитки | 8–16 | Всегда |
| Алмазы | 2–5 | Всегда |
| Зачарованное золотое яблоко | 1–3 | Всегда |
| Первое оружие из 28 моделей, включая четыре дробовика | 1 | Равные шансы моделей |
| Второе оружие | 1 | Шанс 25%, независимая выборка из того же списка |
| Патроны | 4 стака на каждое оружие | Подходящий калибр |
| Обвес | 1 на каждое оружие | Случайный совместимый, гарантирован |
| Шлем | 1 | Только Fracture Point, 8 вариантов |
| Нагрудник | 1 | Только Fracture Point, 8 вариантов |
| Поножи | 1 | Только Fracture Point, 8 вариантов |
| Ботинки | 1 | Только Fracture Point, 8 вариантов |
| Защитная пластина | 1 | Шанс 50%, один из пяти типов |

Для каждого слота брони отдельно выбирается одна вещь из Ratnik, Beta 7,
Insurgency Commander, Soviet, SSO, FSB, IZ Forest и IZ Desert. В награде нет
обычной брони и рюкзаков. Пластина выбирается из стальной III, керамической IV,
кевларовой IIIA, композитной IV и полиэтиленовой III с одинаковыми весами.

Максимальный комплект занимает 21 стак до объединения, без отдельного бонуса.
Патроны и обвес относятся к выбранному оружию; при выпадении второго оружия
выдаётся второй полный комплект. Две независимые выборки оружия могут совпасть.
Для общих калибров запас на каждое оружие соответствует таблице сундуков;
для дробовиков награды — 32–64 патрона 12 Gauge. Обвес у DB Long выбирается
из разрешённых этим оружием модификаторов патронов TaCZ.
Barrett M95/M107 и AWM исключены из обоих пулов. В сундуках по-прежнему обычные
золотые яблоки, в наградах — зачарованные.

На основном сервере отдельный бонус — `tacz:barret_core` в количестве одной штуки.
Он разыгрывается дополнительно к основной награде с учётом числа участников
при старте боя: от 20% при 16 до 100% при 32. Шкала шансов сохранена.

Для замены прежней звезды измените только `bonus.item` в `settings.json`
на `tacz:barret_core`. Рядом с пресетами находятся `bonus.patch.json`
и `Apply-Bonus.ps1`. Пример автоматического применения с резервной копией:

```powershell
.\Apply-Bonus.ps1 -SettingsPath 'C:\server\config\hungergames\settings.json'
```

Скрипт сохраняет количество, вероятности и остальные настройки. После применения
выполните `/hg reload` вне события. `bonus.patch.json` — фрагмент для изменения
настроек; сам по себе мод его не загружает. Предмет должен быть зарегистрирован
на целевом сервере. На тестовом сервере его нет; замена предназначена для основного.

Для переноса установите Hunger Games 1.1.0, скопируйте `chest_loot.json`
и `rewards.json` в `config/hungergames`, затем перезапустите сервер.
При последующем редактировании только пулов достаточно `/hg reload` вне события.
Загрузчик мода проверяет оба пула перед
применением; ошибочная конфигурация не заменяет предыдущую рабочую версию.
