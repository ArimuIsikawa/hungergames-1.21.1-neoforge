## 1. Согласованные требования

- [X] Hunger Games устанавливается только на сервер; клиентам отдельный мод Hunger Games не требуется.
- [X] Набор открывается ежедневно в 20:00 по Москве, часовой пояс `Europe/Moscow`.
- [X] Сервер сообщает об открытии набора в общий чат и приглашает использовать `/hg invite`.
- [X] Если за 15 минут не набралось минимум четыре игрока, набор закрывается.
- [X] Одновременно участвуют от четырёх до восьми игроков.
- [X] Вход разрешён только с пустыми инвентарём, бронёй, второй рукой и аксессуарами.
- [X] После входа игрок переносится в зону ожидания; исходное место сохраняется.
- [X] При четырёх участниках начинается отсчёт в три минуты; при восьми оставшееся время сокращается до 15 секунд.
- [X] При числе участников меньше четырёх отсчёт сбрасывается. В остальных случаях таймер не сбрасывается.
- [X] Игра проходит на готовой карте в отдельном измерении.
- [X] Команда `/hg set_spawn <player_num>` сохраняет текущее положение как точку появления участника с номером от 1 до 8.
- [X] Сундуки уже размещены на карте; перед каждым боем они заполняются случайным лутом из общего пула.
- [X] Арена неразрушаемая: игрокам запрещены установка и разрушение блоков.
- [X] Зона боя сужается; для её реализации предполагается использовать границу мира.
- [X] После старта нет периода неуязвимости.
- [X] При смерти вещи выпадают, а игрок становится наблюдателем.
- [X] Команда `/hg leave` позволяет покинуть очередь или наблюдение.
- [X] Отключение от сервера само по себе не считается поражением.
- [X] После перезапуска сервера игроки возвращаются на сохранённые места вне игрового измерения.
- [X] Последний оставшийся участник становится победителем: поздравление, очистка игрового инвентаря, возврат, выдача награды.
- [X] Основные награды и лут сундуков задаются отдельными JSON-пулами; содержимое позже заполнит администратор.
- [X] Звезда незера — отдельный бонус к основной награде; предмет бонуса должен быть заменяемым через настройки.
- [X] Вероятность бонуса зависит от числа участников в момент начала боя: 4 → 20%, 5 → 40%, 6 → 60%, 7 → 80%, 8 → 100%.
- [X] Нужны административные команды, включая `/hg create_event`, и команда просмотра `/hg spectator`.

- [ ] Проверять основной инвентарь, панель быстрого доступа, броню, вторую руку и предмет на курсоре открытого меню.
- [ ] Через Curios проверять все обычные и косметические слоты, включая добавленные модами сборки; занятый рюкзак или нагрудник с хранилищем также препятствует входу.
- [ ] При отказе сообщать игроку, что нужно освободить инвентарь или аксессуары; не удалять и не складывать его личные вещи автоматически.

- [ ] Если участников стало меньше четырёх, сбросить отсчёт; при повторном достижении минимума начать новый отсчёт.
- [ ] При остальных изменениях числа участников сохранять текущий таймер, включая уход восьмого игрока после сокращения до 15 секунд.

- [ ] Перед боем зафиксировать состав и число участников для расчёта бонуса, подготовить сундуки и границу, распределить игроков по заданным точкам.

## 12. Решения, которые ещё нужно уточнить

- [ ] Взаимодействие 15-минутного окна и отсчёта: если четвёртый игрок пришёл в 20:14, можно ли закончить трёхминутный отсчёт после 20:15? Что делать, если к закрытию набора снова осталось меньше четырёх?
- [ ] Участники, отключённые в очереди: сохранять ли им место и можно ли начинать бой, пока часть зарегистрированных игроков не в сети?
- [ ] Длительное отключение в бою: статус живого сохраняется, но остаются открытыми предел длительности матча, возможное ожидание возврата и результат при отсутствии всех оставшихся участников. Не вводить автоматическое поражение за отключение без отдельного решения.
- [ ] Поведение `/hg leave` для живого участника: добровольное поражение с выпадением вещей или запрет до смерти. Выход из очереди и наблюдения уже согласован.
- [ ] Правила внешних наблюдателей: требуется ли пустой инвентарь, как сохраняются личные вещи, доступна ли команда всем игрокам и где разрешено перемещаться.
- [ ] Параметры сужения границы: размеры, этапы, продолжительность и урон. Также нужны границы готовой карты, точка ожидания и исходный размер зоны.
- [ ] Состав распознаваемых сундуков: только обычные/двойные или также Iron Chests, сундуки-ловушки, бочки и другие контейнеры.
- [ ] Схема выдачи основной награды: одна случайная запись или несколько выборок. Аналогично нужны диапазон заполнения и допустимость повторов предметов в сундуках.
- [ ] Расписание после простоя: запускать ли пропущенный набор при включении сервера после 20:00; что делать с плановым открытием, если ручное событие ещё активно.
- [ ] Изоляция игровых предметов от других серверных возможностей: уточнить имеющиеся команды телепортации, удалённые хранилища и другие способы переноса вещей, которые должны ограничиваться на событии.
